# <img src="images/pwf2tools-x64.png" align="center"> ezmorib-dehash - A sleek GUI for Mojib-Ribbon file hashing! </img>

ezmorib-dehash is a tool for the game "Mojib-Ribbon" that de-hashes (and re-hashes) its files to or from the hashed format that the game comes with. It is released under the TFRPL (my custom license!). It's free to use and open source (and always will be!). The icon is drawn by [@p4ckles](https://twitter.com/p4ckles).

# Installing and using
Currently, you must install from source. To build ezmojib-dehash currently, you need the following dependencies on your system: **CMake 3.5** (or newer), **Qt6** (or newer), and a **C/C++ compiler**. At the root of the directory, you will need to run these commands:

    mkdir build
    cd build
    cmake ..
    make

## Outputs
The output executable will be simply called "ezmojib-dehash(.exe)"
